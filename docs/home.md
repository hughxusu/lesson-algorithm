# 数据结构与算法

**本站网址**  https://hughxusu.github.io/lesson-algorithm/

**[代码仓库](https://github.com/hughxusu/lesson-algorithm)**

## 课程目标

* 学习数据结构和算法的理论知识，可以使用Python语言实现相关内容。
* 解决算法问题时，有一个合理的思考路径。
* 面对算法问题，不畏惧。

## 课程内容

* 了解学习数据结构和算法基础理论。
* 学习常见的数据结构，并使用Python实现。
* 学习常见算法，并使用Python实现。
