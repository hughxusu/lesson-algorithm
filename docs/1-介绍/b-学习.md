# 如何学习

算法理论的特点：

* 专注于数学证明和推导，处理抽象的、普遍的问题和理想化的模型。
* 分析算法的普遍性质，包括：时间复杂度、空间复杂度、正确性证明和最坏情况分析。
* 不考虑实际工程细节。

算法实践的特点：

* 不关注理论证明，只追求结果。
* 从实际问题出发，选择合适的算法，并非效率最高的算法。
* 考虑工程细节和约束，包括：硬件限制、代码可维护性等。
* 算法实践的重要应用领域——**算法面试和算法笔试**
  * 算法面试的水平远低于信息学竞赛。
  * ACM-ICPC（国际大学生程序设计竞赛）
    * 顶尖大厂（Google、微软、字节、阿里等）优先录用ICPC获奖选手。
    * 保研、留学申请的硬核加分项。
    * 赛事比较：
      * ACM-ICPC：最高（国际级）。
      * 蓝桥杯：国家级。
      * CCPC：同ICPC规则，国内顶级。


## 算法实践的学习路径

实践算法知识不等于研究《[算法导论](https://book.douban.com/subject/20432061/)》

* 算法导论强调理论证明，实践中只关心程序的运行结果。
* 高级的数据结构和算法在实践中用到的概率非常低，如：FFT、红黑树、数论等。
* 学习《算法导论》时，不要过于专注理论证明
  * 应该先理解并记住结论。
  * 将结论应用于实践。
  * 不要追求一次学明白，可以反复研究。

## 解决算法问题的一般思路

算法问题不依赖

### 注意题目中的条件

题目中的条件能够帮助我们选择合适的算法

* 给定有序数据。
* 设计$O(n\log n)$的算法。
* 数据规模在一万左右。

### 穷举法

解决问题没有思路时：

* 建立几个简单的测试用例。
* 不要忘记穷举法，穷举法通常是思考的起点。

> [!tip]
>
> 在一个字符串中寻找没有重复字母的最长子串，如：abcabcbb，最长子串为abc？

1. 遍历得到字符串中所有的子串s[i…j]。
2. 判断每个子串中是否有重复字母。
3. 找出没有重复字母最长的子串。

获得所以子字符串的穷举法

```python
def longest_substring_brute(s):
    n = len(s)
    
    for i in range(n):
        for j in range(i + 1, n + 1):
            substr = s[i:j]
            print(substr, end=" " * 4)
        print()
```

> [!important]
>
> 理论上任何问题都存在一个穷举法。

#### 三种常见双循环

双循环穷举法模型，经常用到下面面的三种形式：

1. 矩形双循环

```python
n = 10
for i in range(1, n):
    for j in range(1, n):
        print(j, end=" ")
    print()
```

2. 上三角双循环

```python
n = 10
for i in range(1, n):
    for j in range(i, n):
        print(j, end=" ")
    print()
```

3. 下三角双循环

```python
n = 10
for i in range(1, n):
    for j in range(1, i + 1):
        print(j, end=" ")
    print()
```

### 算法的优化

研究算法的目的，是提出一个优化的算法：

1. 从常见的算法角度优化。
2. 从数据结构角度优化。
3. 用空间换时间。
4. 对数据进行预处理，如：排序。
5. 在瓶颈处寻找答案。

> [!warning]
>
> 借助图形理解算法的流程。

### 代码实现

1. 异常条件处理。数组是否为空，字符串是否为空，0值，等…
2. 代码规范和可读性。

> [!warning]
>
> 算法学习是一个长期积累的过程。

## 关于算法面试

* 算法面试时要重视基础算法和数据结构，不要一味追求问题的难度。
* 算法面试时，要能向考官展示合理的思考路径，即向面试官证明自己解决问题的能力。
* 算法面试可以看做和面试官一起讨论，一个解决问题的方案。
  * 和面试官沟通细节和边界条件。
  * 和面试官沟通数据特征。
  * 和面试官沟通数据结构和存储方式。
* 算法面试中解决问题不仅仅是正确，而需要更优。
* 算法面试中解决问题需要从实际问题出发，综合衡量算法的选择。
* 算法面试中应注意代码的规范性和容错性。
* 算法面试中可以手写程序。
